📊 Model Evaluation

Each model is evaluated on the held-out test set using the following metrics:

  • Accuracy — overall percentage of correct predictions.
  • Precision — of the students predicted "Placed", how many actually were.
  • Recall — of the students actually placed, how many the model correctly identified.
  • F1-score — harmonic mean of precision and recall.
