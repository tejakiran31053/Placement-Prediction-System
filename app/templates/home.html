Home Page

Welcome to the Placement Prediction System — a Machine Learning project built with Flask that predicts whether a student will be placed based on their academic performance, test scores and profile details.

What this app covers

Page What it shows
Dataset Raw dataset shape, columns and a preview of the first few records.
EDA Exploratory Data Analysis charts — distributions, correlations and relationships between features.
Preprocessing How missing values, scaling and categorical encoding are handled before training.
Models The machine learning models trained on the dataset: Logistic Regression, Decision Tree, Random Forest and Gradient Boosting.
Evaluation Accuracy, precision, recall, F1-score and confusion matrix for each model.
Comparison Side-by-side comparison of every model, ranked by accuracy.
Prediction An interactive form to enter a student's details and get a live placement prediction.

Target Variable

PlacementStatus — whether a student was placed (1) or not placed (0).
